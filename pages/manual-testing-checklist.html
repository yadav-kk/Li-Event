System Testing & Verification Checklist

Complete step-by-step testing manual for the Literacy India Event & Competition Management System.
1. Super Admin & Program Admin Roles super_admin prog_admin
Done Step Test Instructions Expected Outcome
1.1 Log in as admin@test.com (Password: password123). Open the Events page. Main dashboard displays with admin counts. Side navigation shows all management tabs.
1.2 Click Create Event. Set future registration dates (e.g. tomorrow) and save. Event successfully saved in PLANNING status. No judge panel links are generated.
1.3 Edit the event dates so registration starts today at 5:00 AM. Refresh dashboard. Sync engine automatically transitions status from PLANNING to REGISTRATION.
1.4 Create/Clone an event. Click on Leads button in the actions column. Mappings modal opens. Add a Coordinator as Lead. Lead is successfully assigned. Leads mapping updates in database without errors.
1.5 Archive an active event. Status changes to ARCHIVED. "Edit" & "Leads" buttons hide. Unarchive button appears.
1.6 Click Unarchive on the archived event. Event transitions back to its correct status (e.g. REGISTRATION or ASSESSMENT) based on today's dates.
2. Centre In-Charge Role centre_incharge
Done Step Test Instructions Expected Outcome
2.1 Log in as a Centre In-charge (e.g. arup.mahato@literacyindia.org, Password: password123). Dashboard loads showing "My Registered Participants" and "Events Aligned with My Centre".
2.2 Go to Participants registry. Download the sample CSV. A CSV template downloads containing columns: Participant Name, Gender, Centre Code, Program Code, Guardian Name, Guardian Mobile, Language (No "Class").
2.3 Fill in 2 student rows using the downloaded template, select the active event, and click Bulk Import CSV. Preview grid shows parsed columns. On Save, students are registered. Under-the-hood class column default constraints set to N/A.
2.4 Go to Evidence Upload. Upload a PDF/Image scorecard for a participant. File successfully registers in Supabase Storage. Link shows up in the uploads table.
3. Judge / Assessor Role judge
Done Step Test Instructions Expected Outcome
3.1 Log in as the Mail Judge (judge@test.com, Password: password123). Open the Judge Panel. All active assessments belonging to events in ASSESSMENT phase appear. Registration/Practice events are hidden.
3.2 Click on an assessment that has expired/closed. Warning banner displays: "This assessment ended...". Input cells are locked/read-only. No scores can be updated.
3.3 Log in as a Super Admin. Go to the same expired assessment sheet. Warning banner says: "Admin Override Mode: You have access to edit". Inputs are unlocked for Super Admin.
3.4 Log in as standard judge (e.g. satya@literacyindia.org) and click an active assessment. Enter scores. Scores save automatically. Total score updates in real time.
4. Event Leads & Results Panel Event Leads
Done Step Test Instructions Expected Outcome
4.1 Log in as a Coordinator who was mapped as Event Lead. Open Results & Rankings. Leaderboard dropdown displays. User has full access to calculate rankings across All Centres.
4.2 Trigger the Disqualify action for a participant on the leaderboard. Confirmation modal opens. On confirm, participant's qualification status changes to DISQUALIFIED and rank updates.
4.3 Click Confirm Rankings & Promote Finalists to advance Stage 1 participants. Qualified finalists are registered to Stage 2. Stage 2 status transitions to SCHEDULED, and its assessments status updates to ACTIVE.
